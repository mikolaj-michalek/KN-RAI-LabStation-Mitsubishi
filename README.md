# KN-RAI-LabStation-Mitsubishi
Repozytorium projektu w ramach działalności Koła Naukowego Robotyka Automatyka Informatyka (RAI) na Politechnice Poznańskiej. Opracowanie stanowiska dydaktycznego w oparciu o komponenty Mitsubishi, obejmujące integrację PLC i HMI, przygotowanie płytek PCB, zaprojektowanie części mechanicznej oraz opracowanie dokumentacji technicznej.
